PTT-FQU 獨立桌面可攜版 (v3.1.2)

【使用方式】
1. 解壓縮整個資料夾，不需安裝 Node.js 或其他軟體。
2. 雙擊「開始使用 PTT-FQU.bat」：
   - 啟動本機服務並自動開啟 PTT-FQU 視窗，不必手動輸入網址。
   - 黑色服務視窗會保持開啟，可最小化；關閉它會停止本機服務。
3. 若啟動失敗，錯誤會留在服務視窗，完整紀錄也會寫入同目錄的 ptt-fqu.log。

【安全與資料】
- 本版本使用 Windows 批次啟動檔，不含自製的未簽章 PTT-FQU.exe 啟動器。
- 本機服務只綁定 127.0.0.1，僅供這台電腦的瀏覽器使用。
- Chrome／Edge 使用 PTT-FQU 專用設定資料夾，與一般瀏覽器資料分開。

【功能】
- 黑白名單：文章列表與推文可透過右鍵加入 ID 或選取關鍵字；支援白名單例外、匯入與匯出。
- 快速看板：可釘選常用看板。
- 免安裝：內含 Node.js 執行環境及必要套件。
