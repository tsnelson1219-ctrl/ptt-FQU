PTT-FQU 獨立桌面可攜版 (v3.0.4)

【使用方式】
1. 解壓縮整個資料夾（請勿只取出單一檔案），不需安裝任何軟體。
2. 雙擊「PTT-FQU.exe」：
   - 在背景啟動本機服務（不會跳出黑色視窗），並自動開啟獨立視窗
     （優先使用 Google Chrome，其次 Microsoft Edge）。
   - 關閉 PTT 視窗後，本機服務會在閒置 30 秒後自動結束。
3. 若 PTT-FQU.exe 沒有反應，改雙擊「啟動 PTT-FQU.bat」：
   - 會顯示黑色視窗與連線紀錄，方便查看錯誤；關閉黑窗即停止服務。
   - 錯誤紀錄也會寫入同目錄的 ptt-fqu.log。
4. 「關閉 PTT-FQU 背景服務.bat」：強制結束本機服務 (Port 38120)。

【注意】
- 請用 http://127.0.0.1:38120/ 開啟，不支援 localhost 或直接開啟 html 檔。
- 獨立視窗的瀏覽器設定存放在同目錄的 .ptt-fqu-chrome-profile，刪除即可重置。

【特色功能】
- 黑白名單系統：於文章列表或推文點擊右鍵即可將特定 ID 或選取關鍵字加入黑名單；內建白名單保護與名單匯入/匯出。
- 快速看板：可釘選常用看板快捷鍵。
- 免安裝：內建獨立 Node.js 執行環境。
