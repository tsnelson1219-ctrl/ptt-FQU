PTT-FQU 可攜版

使用方式
1. 將整個封裝資料夾解壓縮到電腦。
2. 點擊「開始使用 PTT-FQU.bat」。瀏覽器會自動開啟 PTT-FQU。
3. 使用期間保持啟動服務的黑色視窗開啟；關閉視窗會停止服務。

此封裝內含 Windows 版 Node.js 執行檔，不需另外安裝 Node.js。第一次啟動及使用 PTT 時仍需網路連線。

黑名單與白名單儲存在瀏覽器的本機儲存空間。若更換瀏覽器或電腦，請先從名單管理匯出，再於另一個環境匯入。

如顯示連接埠 38120 已被使用，請關閉佔用該連接埠的程式後再重新啟動。
